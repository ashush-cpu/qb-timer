# QB 解説3分タイマー

QB は演習2分・解説3分で区切る。そのための、音も数字も出さない静かなタイマー。

**使う：** https://ashush-cpu.github.io/qb-timer/

- 演習 → 解説 → 次の問題、のサイクルをボタン1つで回す
- 演習に入って2分、解説に入って3分たつと背景色だけが控えめに変わる
- 「終わる」で今日の問題数と直近8週間の積み上げを表示
- 記録は端末の中（localStorage）にだけ保存。サーバーには何も送らない

## 使い方

- **iPad / iPhone**：Safari で開き、共有 →「ホーム画面に追加」。アプリのように全画面で起動する。
- **PC（Chrome / Edge / Firefox）**：「小窓」ボタンで右上に小さく常駐させられる。
- **キーボード**：Space / Enter で次へ、P で一時停止。

## 開発

ビルド不要。`index.html` を直接編集する。

- インラインスクリプトを変えたら `node scripts/csp-hash.js` で CSP のハッシュを更新する。
- `sw.js` の `VERSION` を上げると、利用者側のキャッシュが更新される。

詳細は `CLAUDE.md` を参照。
